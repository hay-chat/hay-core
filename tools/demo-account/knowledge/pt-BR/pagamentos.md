# Formas de pagamento: Casa Aurora Brasil

## Como pagar

- **Pix:** aprovação na hora. O código Pix (copia e cola) tem validade; se vencer, o pedido é
  cancelado automaticamente.
- **Boleto:** o banco confirma o pagamento em até 3 dias úteis. O pedido só é enviado depois.
- **Cartão de crédito (Mercado Pago):** à vista ou parcelado, conforme as opções do checkout.

## Perdi o código Pix ou o boleto

- Se o pedido ainda não foi pago, a IA pode enviar de novo o código Pix, o boleto ou o link de
  pagamento. Para isso, ela confirma o e-mail ou telefone do pedido. Se não bater, nada é enviado.

## Já paguei e o pedido aparece como pendente

- Pix costuma aparecer em minutos; boleto pode levar até 3 dias úteis.
- Se passou disso, a IA passa para a equipe conferir. Você pode mandar o comprovante no chat.

## Nunca envie dados de cartão no chat

A gente nunca pede número de cartão, CVV ou senha. Fotos de cartão ficam ocultas para a IA.
