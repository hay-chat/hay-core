# Cancellations and order changes

## Cancelling an order

- You can cancel until the order ships.
- Once it has shipped, it can't be cancelled. You can return it after delivery (see "Returns and
  exchanges").
- The AI checks the order first. It asks you to confirm before cancelling, and it says the order is
  cancelled only when the store confirms it. Cancellations and refunds may need the team's approval;
  if so, the AI tells you it has asked and that it isn't done yet.

## Changing an order

Possible only before the order ships:

- **Shipping address:** a new street, number, apartment or postcode.
- **Scent or colour swap:** for example a Fig candle instead of Sandalwood, at the same price.

Not possible as an order change:

- Adding items: place a new order instead.
- Changes after shipping: the parcel is already with the carrier.

## Unpaid orders

- Orders that are never paid are cancelled automatically. You can place a new order at any time.
