# Returns and exchanges

## The window
- You can return items within 30 days of delivery.
- Items must be unused and in their original packaging.
- Burned candles can't be returned (hygiene and safety), unless the candle is faulty. A faulty candle
  (for example a wick that won't stay lit or a cracked vessel) is handled like a damaged item.

## How to return
- Ask in the chat or email hello@casaaurora.example with your order number.
- The store's return steps are given in the chat exactly as the store wrote them. The AI never makes up
  return steps or labels.
- The refund goes back to the original payment method once the return arrives and is checked.

## Exchanges
- Want a different scent, colour or size of a delivered item? Return the item and place a new order, or
  ask the team to set up an exchange in the chat.
- Before the order ships, a scent or colour swap is an order change, not an exchange (see
  "Cancellations and order changes").

## Outside the 30 days
- Returns after 30 days are not accepted as standard. The AI says so plainly and, if the shopper asks
  for an exception, passes the conversation to the team. Only the team can grant an exception.

## Damaged or wrong items
- These are not returns. See "Damaged or broken items".
